###### \---



## WebRecon Functionality 



Let's go through each option one by one:



**1. Show menu:**  

Displays the main menu.



**2. Set target:** 

This option sets a permanent URL that will be used in all subsequent processes. The URL format must comply with the following examples:  
https://google.com or http://google.com
Using any other protocols will result in an error.



**3. Scan website:**

Scans all directories of the website listed in the `wordlist.txt` file.


**4. Show wordlist:** 

Displays the contents of the `wordlist.txt` file.



**5. Add path:**

Adds the specified directory to the `wordlist.txt` file.



**6. Remove path:** 

Removes the selected directory from the `wordlist.txt` file.



**7. Save report:**

Generates and saves a report to the `report.txt` file. It includes data analysis and optionally raw data.



**8. View result:**  

Displays only the raw data obtained after scanning.



**9. Analyze result:**  

Analyzes the data obtained during the scan and generates a statistical report.



**10. Exit:**  

Exits the program.

## WebRecon Functionality 



Разберем каждую опцию по отдельности:



**1. Show menu:**

Отображает главное меню.



**2. Set target:**

Опция указывает постоянный URL который будет использоваться во всех последующих
процессах. Формат URL обязан соответствовать следующим примерам:
https://google.com или http://google.com
Использование иных протоколов передачи приведет к ошибке.


**3. Scan website:**

Проводит сканирование всех указанных в файле wordlist.txt директорий сайта.


**4. Show wordlist:**

Выводит содержимое файла wordlist.txt.


**5. Add path:**

Добавляет в файл wordlist.txt указанную директорию.

**6. Remove path:**

Удаляет из файла wordlist.txt выбранную директорию.

**7. Save report:**

Формирует и сохраняет репорт в файл report.txt, содержит в себе анализ данных
и сырые данные (опционально).

**8. View result:**

Исключительно сырые данные, полученные после сканирования.

**9. Analyze result:**

Анализирует данные полученные в ходе сканирования и формирует статистический отчёт.

**10 Exit:**

Выход.
